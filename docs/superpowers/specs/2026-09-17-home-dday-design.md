# 홈 대회 D-day · 설계

- 날짜: 2026-09-17
- 참고: 시즌1에도 D-day가 있었다(홈 `DdayCard` + 헤더 우측 + 체중 그래프 점선). 2026-06-26 시즌2 리브랜딩(`b437156`)에서 `SHOOT_DATE`/`getDday`/`DdayCard`와 함께 전부 제거됐다.

## 1. 목적

어반웨이브 대회(**2026-10-18 일**)까지 남은 일수를 홈에서 보여준다. 시즌1처럼 전용 카드를 새로 만들지 않고, 이미 있는 운동 통계 카드에 합친다 — 홈에 카드를 하나 더 쌓지 않기 위해서.

## 2. 레이아웃

기존 통계 카드(이번 달 크게 / 이번 주 작게)를 아래로 바꾼다.

```
┌───────────────────────────────────┐
│ Urban Wave          이번 달 운동  │
│                             11일  │
│ D-30                이번 주 운동  │
│                              3일  │
└───────────────────────────────────┘
```

- **왼쪽**: 대회명(작게) + D-day(`text-4xl`, `accent-pop` 금색). 카드에서 가장 큰 글자.
- **오른쪽**: 이번 달 운동 / 이번 주 운동을 위아래로, 둘 다 `text-lg`로 작게.

**대회가 지나면 왼쪽을 숨기고** 오른쪽 두 지표만 남는다(가로로 펼쳐 기존 모습에 가깝게). 끝난 카운트를 계속 띄우지 않기 위해서다. 다음 대회를 넣을 땐 `EVENT` 상수의 날짜·이름만 바꾸면 된다.

## 3. 구현

`src/lib/workout/dday.ts` — 순수 함수, DB·컴포넌트 의존 없음:

```ts
export const EVENT = { name: 'Urban Wave', date: '2026-10-18' }
export function daysUntil(target: string, today: string): number   // 당일 0, 지나면 음수
export function formatDday(days: number): string                   // 'D-30' | 'D-DAY' | 'D+3'
```

`daysUntil`은 `'YYYY-MM-DD'` 두 개를 **UTC 자정끼리** 빼서 서머타임·타임존 영향을 없앤다. 시즌1 `getDday()`는 `new Date()`를 함수 안에서 직접 읽어 테스트할 수 없었는데, 여기선 `today`를 인자로 받는다.

`formatDday`는 `D+n`까지 처리하지만 홈에서는 `days >= 0`일 때만 렌더한다 — 대회 후 표시 정책이 바뀌면(예: 며칠간 `D+n` 유지) 홈 조건만 고치면 된다.

`src/app/page.tsx`는 `toDateString(now)`로 오늘을 만들어 전달하고 위 레이아웃을 렌더한다.

## 4. 검증

- `dday` 단위 테스트 8개: 남은 일수 / 당일 0 / 지나면 음수 / 월·연 경계 / `D-n`·`D-DAY`·`D+n` 표기 / `EVENT` 값 고정.
